# 04 - Công Cụ BA Cần Biết

## Phân Nhóm Công Cụ

---

## 📝 Nhóm 1: Requirements & Documentation

### Confluence
- **Dùng để làm gì:** Viết và lưu trữ tài liệu yêu cầu, meeting notes, specs
- **Tích hợp tốt với:** Jira
- **Phù hợp:** Môi trường Agile, doanh nghiệp vừa và lớn
- **Học ở đâu:** Atlassian University (miễn phí)

### Jira
- **Dùng để làm gì:** Quản lý User Stories, backlog, sprint, bug tracking
- **Tính năng BA dùng nhiều:**
  - Tạo và quản lý Epic / Story / Task
  - Gán acceptance criteria
  - Theo dõi tiến độ sprint
- **Phù hợp:** Agile/Scrum teams
- **Học ở đâu:** Atlassian University, YouTube

### Azure DevOps
- **Dùng để làm gì:** Quản lý yêu cầu, backlog trong môi trường Microsoft
- **Phù hợp:** Dự án dùng stack Microsoft (.NET, Azure)
- **Tính năng:** Work Items, Boards, Repos, Pipelines

### Microsoft Word / Google Docs
- **Dùng để làm gì:** Viết BRD, FRD, SRS, báo cáo phân tích
- **Khi nào dùng:** Môi trường Waterfall, tài liệu chính thức cần ký duyệt

---

## 📊 Nhóm 2: Diagramming & Modeling

### draw.io (diagrams.net)
- **Dùng để làm gì:** Vẽ BPMN, flowchart, ERD, UML, wireframe
- **Ưu điểm:** Miễn phí hoàn toàn, tích hợp Google Drive / Confluence
- **Là công cụ số 1 nên học đầu tiên**
- **Học ở đâu:** [diagrams.net](https://www.diagrams.net)

### Lucidchart
- **Dùng để làm gì:** Tương tự draw.io nhưng có tính năng cộng tác real-time tốt hơn
- **Phù hợp:** Team làm việc remote
- **Chi phí:** Có bản free với giới hạn

### Microsoft Visio
- **Dùng để làm gì:** Vẽ sơ đồ enterprise-level
- **Phù hợp:** Môi trường doanh nghiệp lớn dùng Microsoft
- **Chi phí:** Tốn phí, thường có sẵn trong gói Microsoft 365

### Balsamiq
- **Dùng để làm gì:** Wireframing giao diện người dùng (low-fidelity mockup)
- **Ưu điểm:** Nhanh, đơn giản, trông như bản phác thảo tay
- **Phù hợp:** BA cần mô tả UI cho developer mà không cần kỹ năng design

### Figma
- **Dùng để làm gì:** Thiết kế UI/UX chi tiết (high-fidelity)
- **Khi nào BA dùng:** Khi cần làm prototype interactive để demo cho stakeholders
- **Lưu ý:** Figma thiên về designer, BA biết dùng cơ bản là đủ

## 🔢 Nhóm 3: Data Analysis

### Microsoft Excel / Google Sheets
- **Dùng để làm gì:**
  - Phân tích dữ liệu nghiệp vụ
  - Tạo requirement traceability matrix
  - Lập báo cáo, pivot table
  - Validate dữ liệu
- **Kỹ năng Excel BA cần:** VLOOKUP, Pivot Table, conditional formatting, data validation

### SQL
- **Dùng để làm gì:**
  - Query database để hiểu cấu trúc dữ liệu
  - Kiểm tra data quality
  - Hỗ trợ viết yêu cầu liên quan đến data
- **Mức độ cần biết:** Basic SELECT, JOIN, WHERE, GROUP BY là đủ
- **Học ở đâu:** SQLZoo, W3Schools, Mode Analytics

### Power BI
- **Dùng để làm gì:** Tạo dashboard và báo cáo trực quan từ dữ liệu
- **Phù hợp:** BA trong lĩnh vực data analytics, reporting
- **Tích hợp:** Microsoft Excel, Azure, SQL Server

### Tableau
- **Dùng để làm gì:** Tương tự Power BI, mạnh về visualization
- **Phù hợp:** Môi trường không dùng stack Microsoft

---

## 🤝 Nhóm 4: Collaboration & Communication

### Miro / Mural
- **Dùng để làm gì:** Whiteboarding online cho workshop, brainstorming
- **Tính năng BA dùng:**
  - Affinity mapping
  - User journey mapping
  - Process mapping
  - Retrospective boards
- **Phù hợp:** Remote team, workshop online

### Microsoft Teams / Slack
- **Dùng để làm gì:** Giao tiếp hàng ngày với team và stakeholders
- **Tính năng quan trọng:** Channels, file sharing, integration với Jira/Confluence

### Zoom / Google Meet
- **Dùng để làm gì:** Phỏng vấn stakeholders, remote workshops, demo
- **Tip:** Luôn record meeting (nếu được phép) để review lại

### Trello
- **Dùng để làm gì:** Quản lý task đơn giản bằng kanban
- **Phù hợp:** Project nhỏ, team startup

---

## 🔧 Nhóm 5: Specialized Tools

### Sparx Enterprise Architect
- **Dùng để làm gì:** UML modeling nâng cao, enterprise architecture
- **Phù hợp:** Senior BA, Enterprise Architect
- **Chi phí:** Tốn phí

### IBM Rational RequisitePro / DOORS
- **Dùng để làm gì:** Quản lý yêu cầu trong dự án lớn (aerospace, defense, banking)
- **Phù hợp:** Dự án compliance-heavy

### Postman (biết sơ qua)
- **Dùng để làm gì:** Test API để hiểu integration giữa các hệ thống
- **Mức độ cần biết:** BA hiểu API là gì và biết đọc API docs là đủ

## Ưu Tiên Học Công Cụ Theo Cấp Độ

### Mới bắt đầu (0–6 tháng)
1. ✅ draw.io — Vẽ sơ đồ
2. ✅ Jira — Quản lý backlog
3. ✅ Confluence — Viết tài liệu
4. ✅ Excel — Phân tích cơ bản

### Intermediate (6 tháng – 2 năm)
5. 🔵 SQL — Query database
6. 🔵 Miro — Workshop online
7. 🔵 Lucidchart — Sơ đồ nâng cao
8. 🔵 Power BI — Báo cáo

### Advanced (2+ năm)
9. 🟡 Figma — Prototype UI
10. 🟡 Tableau — Advanced analytics
11. 🟡 Sparx EA — Enterprise modeling

---

> 💡 **Tip thực tế**: Bạn không cần giỏi tất cả — hãy thành thạo **Jira + Confluence + draw.io + Excel + SQL** trước. Đây là bộ công cụ 80% BA dùng hàng ngày.
